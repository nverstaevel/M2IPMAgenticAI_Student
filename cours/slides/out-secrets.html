CM1 · OUTILLAGE · CLÉS, COÛTS, DONNÉES

Trois précautions avec une API hébergée

Clés

Jamais dans Git : variable d’environnement ou fichier local ignoré. Une clé publiée par erreur doit être révoquée aussitôt.

Coûts

Facturation au token, en entrée et en sortie. Bornez la sortie, fixez un budget de tokens, mesurez.

Données

Pas de données personnelles réelles vers un service externe sans cadre (RGPD). Le journal DEBUG contient les prompts : ne le partagez pas.
