CM1 · CONCEVOIR UN OUTIL

La description d’un outil est un prompt

À éviter

« Cherche des trucs dans la base ». Un paramètre String x. Une exception brute en cas d’erreur.

À écrire

Ce que fait l’outil et quand l’utiliser. Chaque argument décrit, avec son format (date AAAA-MM-JJ). Ce qui est renvoyé. Un message d’erreur lisible.

@Tool(description = "Liste les créneaux libres d’un soigneur à une date")
public List<Creneau> creneauxLibres(
    @ToolParam(description = "Identifiant du soigneur") long soigneurId,
    @ToolParam(description = "Date, format AAAA-MM-JJ") LocalDate date)
